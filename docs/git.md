# Git 규칙

## 브랜치 전략

| 브랜치 | 설명 |
| ------- | ---- |
| main | 배포 브랜치 |
| develop | 개발 브랜치 |

---

## 커밋 컨벤션

| 타입 | 설명 |
| ---- | ---- |
| feat | 기능 추가(UI 포함) |
| fix | 버그 수정, 레이아웃 깨짐 수정 등 |
| refactor | 기능 변화 없는 코드 구조 변경 |
| style | 코드 정리, UI만 수정 등 |
| chore | 설정 및 라이브러리 |
| docs | 문서 수정 |
| test | 테스트 |

예시

```
feat: 로그인 기능 구현
feat: 회원가입 페이지 추가

fix: 로그인 오류 수정

refactor: 회원 API 분리

style: 들여쓰기 및 공백 수정

chore: 초기 프로젝트 의존성 설치

docs: 코드 컨벤션 작성
```

---

## Pull Request

PR 제목

```
[feat] 로그인 기능 구현
```

내용

```
## 작업 내용

- 로그인 API 연동
- 로그인 UI 구현
- 예외 처리

## 확인 사항

- 로그인 성공
- 로그인 실패
```
